# 光球对决 · 概念文档

## 一句话
俯视角 1v1 光球对决：一击必杀、三键极速对抗，而你的对手正是你自己上一关的影子——**你在教你的敌人杀你自己**。

## 设计支柱（Pillars）
1. **一击定生死** — 没有 HP、没有容错，每一次出手都是赌命。所有数值与判定围绕"一次接触分胜负"展开。
2. **三键极速** — 移动（WASD）、攻击（左键）、闪避（右键）三个动词，全部即时响应、零惯性、快节奏。动词优先：闪、劈、走。
3. **你在教你的敌人杀你自己** — 教学关的每一笔操作都会被镜像 AI 复刻成第一关的杀招。玩家的心理曲线是：安全地练习 → 发现敌人用"我的招"打我 → 被迫戒掉自己教出去的坏习惯 → 击败昨天的自己。
4. **特效即反馈** — 一击必杀意味着没有血条可看，游戏感全靠特效承载：攻击突进、闪避残影、死亡爆裂、贴脸擦弹慢放。

## MDA 分析
| 层 | 内容 |
|---|---|
| 机制 M | 一击必杀；闪避带无敌帧；攻击=朝准星突进；镜像 AI 逐帧复刻玩家上关轨迹，攻击方向实时瞄准玩家 |
| 动态 D | 拉扯走位、骗招、贴脸擦弹；高阶玩法：**故意喂垃圾习惯**——在教学关乱打乱闪，第一关的幽灵就会复刻这些破绽，玩家可以"设计"自己的敌人 |
| 美学 A | 紧张、精通、自嘲式的自我对峙（"这招是我教它的"） |

## 核心循环（文字版）
观察幽灵轨迹 → 预判它的攻击时机（因为那是我自己的习惯）→ 走位引诱 → 幽灵出招瞬间右键闪避穿过 → 左键突进反杀 → 一击分胜负 →（死亡则立刻重开，单局 10~60 秒）

## 学习→复刻心理曲线（支柱级亮点）
- **教学关（0~2 分钟）**：木桩不动不还手，玩家在此建立肌肉记忆——怎么走、怎么劈、怎么闪。玩家感觉"绝对安全"。
- **转折瞬间**：木桩死亡的特效爆发未散，"第一关"横幅亮起，对面的光球开始复刻你刚才的一切。玩家第一反应往往是"它在学我？"。
- **第一关**：幽灵的走位习惯 = 玩家的习惯。玩家莽，幽灵就莽；玩家龟，幽灵就龟。破局唯一途径是**打出和教学关不一样的自己**。
- **余味**：胜利结算显示"你击败了你自己 · 用时 X 秒"。

## 范围分层
**Must（MVP，必须）**
- 移动/攻击/闪避三系统 + 一击必杀判定
- 教学关木桩（不动不还手）
- 镜像 AI：轨迹逐帧回放 + 攻击实时瞄准
- 教学关→第一关流转、死亡重开、胜利结算

**Should（应有）**
- 闪避残影、死亡爆裂粒子、擦弹慢放、屏幕震动
- Web Audio 音效（挥击/闪避/死亡）
- 幽灵循环圈数提示（第 N 圈）

**Could（可有）**
- 每循环一圈幽灵攻击前摇缩短 5%（压力递增，上限 30%）
- 最佳用时记录（localStorage）
- 回放观看器（观看"我的幽灵"完整轨迹）

## 设计红线自查
- **主导策略**：纯龟缩无法获胜（攻击是唯一击杀手段，无远程），闪避不能取消判定帧外的无敌 → 无必胜套路。
- **经济/数值失衡**：单局制无经济系统；闪避冷却 500ms vs 攻击循环 270ms 保证攻方有节奏窗口。
- **认知过载**：仅 3 个输入 + 2 个实体，教学关承担全部教学职责。

## v2.0 增量 ·「主菜单与多模式」（2026-10-14 用户新指令，已拍板）

### 美学扩展（支柱 3 的世界级升华）
v1.x 的镜像 AI 是「你在教你的敌人杀你自己」；v2.0 把这句话升级为**世界级**：
- **挑战自我**：留下的是你自己——一条由你的过去构成的天梯，越深处的幽灵越强（因为它活得越久、杀得越多）。
- **联机挑战**：全服玩家的操作汇成一个共享幽灵池——你击败的每个对手都是某个真实玩家的过去，你失败的操作也会成为别人的关卡。「每个幽灵背后都是一个真实的人」。
- **boss 体系**：那些杀满千人而不死的操作，被世界加冕为 boss——联机 boss 杀满 1000 人封神，终极 boss 顺位矗立，全服排队挑战同一尊。单机 boss 则是你自己养出来的怪物（20 胜晋级）。
一句话：**v2.0 让「操作」成为可流通、可封神、可永生的货币。**

### MDA 增量
- 机制：五池资产流转（进/抽/替/晋/删）、8 个阈值计数器、灰显入口。
- 动态：养蛊（故意喂强操作给挑战自我，养出 20 胜怪自己打 boss）、全服协作推终极boss顺位、收集/挑战欲驱动重复游玩。
- 美学：传承感（你的操作在死后继续杀人与被杀）、世界性对抗（异步的、跨越时间的 PvP）。

### 范围分层增量
- Must：主菜单 IA（含灰显）、五模式流转、8 阈值计数、服务端三池权威 API 语义、localStorage 双池。
- Should：HUD 进度条动画、告别画面、断线 toast。
- Could：boss 条目来源标记（"第 20 个受害者"署名位，预留字段不展示）、池状态统计页。

### 红线自查增量
- 认知过载：菜单两层、对局内仅加进度条，核心三键操作不变。
- 经济失衡：无付费/资源，唯一货币 replay 流转闭环自洽（进=对局产出，出=删除/晋级）。

### v2.0 已拍板决策（主理人裁定）
| # | 决策项 | 结论 | 理由 |
|---|---|---|---|
| 10 | 联机形态 | 异步幽灵对战，无实时 netcode | 用户规则全是录放+计数，服务端只需存储/抽取/原子计数 |
| 11 | 菜单 UI 形态 | DOM overlay（ADR-005 胜出，menu.md 原 Canvas UI 句作废） | 按钮/置灰/hover/进度条 DOM 成本近零 |
| 12 | 资产货币 | replay 为唯一货币，五池差异=流转规则 | 复用现有 Recorder/GhostPlayer |
| 13 | 持久化分层 | 挑战自我+单机boss=localStorage；联机三池=服务端权威 | 本地无并发需求；服务端 CAS 保经济正确 |
| 14 | 联机池自举 | 单机挑战镜像关胜利 replay 自动播种联机池 | 解决空池死锁（歧义 #1 保守口径） |
| 15 | DRAW/放弃/断线 | 一律无效对局，不产 replay 不计数 | 一击必杀下平局无信息量 |
| 16 | 实现分期 | 一期纯本地（solo/self/boss_solo），二期接云服务（联机三模式） | GhostStore 接口是唯一接缝，二期零返工 |

## v2.2 增量 · 三次击杀与实体碰撞（拍板记录）

### 规则变更
1. **废除一击必杀 → HP=3**：双方各 3 点，打空才死。支柱 1 由「一击定生死」修订为**「三击分生死」**——容错提升但单局仍紧凑（3 次有效接触分胜负）。
2. **攻击期无敌**：起手+判定帧无敌（后摇可被打）；打在无敌上=无效命中。
3. **对撞弹开（废除「后撞的赢」）**：双方判定帧接触 → 沿连线弹开、双方不掉血、各进 300ms 轻弹开。v1.1 拍板的 startTick 裁决正式退役；DRAW 状态 dormant（保留代码无触发源）。
4. **实体碰撞**：两球不可穿过，软推挤分离，无伤害。
5. **固定站位**：玩家恒左 (230,360)、幽灵恒右 (1050,360)，offset=(820,0) 由 CONFIG 推导；「主客互换」设定作废。

### MDA 增量
- 机制：3 点血量、攻期无敌、对撞弹开、实体碰撞、顶部血条。
- 动态：连招压迫（3 套有效命中终结）、无敌帧博弈（用攻击无敌顶着对手冲撞推进 vs 被防御弹开 400ms 重罚）、卡位挤压（实体碰撞把"走位"升级为"占位"）。
- 美学：「它学会了你」的镜像叙事不变；血条让"拆掉你三次"的**进度**具象可见。

### 红线自查
- **主导策略观察项（移交 QA）**：攻击循环 200ms 中无敌 150ms——连续冲撞推进理论上难解，反制为防御弹开 400ms（攻击者硬直窗口）与对撞弹开；实测若"无敌推进"无解，回调优先级：无敌期缩短（仅判定帧无敌）> 弹开 300→400ms。
- 认知过载：仅增血条一处 UI；操作三键不变。

## v2.3 增量 · 防御冷却与镜像复刻（拍板记录）

### 规则变更
1. **防御冷却重做**：最长防 3 秒；提前松开=冷却返还已防时长（防御 2s 还 2s）；被打碎裂或满额结束=冷却 3s。**200ms 防抖废除**——瞬发松开 ≈ 0 冷却是有意的「预判弹反」空间。
2. **幽灵镜像复刻（取代纯复刻）**：轨迹 x 轴镜像 + 冲撞方向 π−dirAngle 镜像；幽灵永远站在"镜子的对面"使出你的招。offset 归零由站位与镜像联合推导（v2.2 的 (820,0) 作废）。
3. 语感升级（支柱 3 措辞）：「你在教你的敌人杀你自己」→ 本版递进为**「它记得你的招，并且站在镜子对面使出来」**。

### MDA 增量
- 机制：三分支冷却、3s 姿态上限、镜像回放。
- 动态：**弹反博弈**（预判对手冲撞时机瞬发举盾再秒收，零成本骗招 vs 被打中即 3s 惩罚窗口）、镜像走位镜像对撞（两球常在屏幕对称位同时起手，画面天然成"照镜子"构图）。
- 美学：对称美学与自我对峙的主题绑定更深一层。

### 红线自查
- **弹反空间观察项（移交 QA）**：瞬发弹反是否过强——预判玩家可在对手起手 50ms 内举盾白吃 400ms 弹开且近乎零冷却。反制：攻击有 50ms 无敌起手可顶着盾收的间隙出手；若实测过强，回调优先级：瞬发下限（<300ms 松开按 300ms 计冷却）> 格挡弹开 400→300ms。
- 防御最长 3s 上限防止永久龟防，自平衡成立。

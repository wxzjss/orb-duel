# GDD · 防御系统（v1.1 新建，替代闪避）

## 1. 概述
右键长按进入防御姿态：原地不动、光晕护体，可挡下第一次冲撞并使攻击者进入弹开眩晕。这是"一击必杀"世界里唯一的防御手段，代价是完全丧失机动。

## 2. 目标
- 格挡成功 = 攻守互换的戏剧节点（防御者获得 400ms 反击窗口）。
- 无限可维持但代价巨大（站桩），由对撞规则与机动缺失自平衡。

## 3. 输入
- 右键 mousedown → 进入防御；mouseup → 结束。需屏蔽 contextmenu。
- 仅在 空闲/移动 状态可进入。

## 4. 规则
- 姿态期：移动锁定（原地不动）、不可冲撞、光晕特效。
- 姿态期受到第一次冲撞命中 → **格挡成功**：
  - 攻击者进入「弹开」强后摇 400ms（眩晕窗口，其间不可冲撞；防御者可立刻反击）；
  - 防御者护盾碎裂特效、防御姿态立即结束。
- 松开右键结束姿态；结束后 200ms 防抖不能再开。
- 防御无使用次数冷却。
- 姿态期不免疫冲撞判定帧的"擦身"——只有打击圈真正命中本体圈才触发格挡。
- 格挡成功的判定优先级高于对撞裁决（被格挡方的冲撞未"命中死亡"，无对撞可言）。
- **护盾碎裂（格挡成功）后的 200ms 防抖与松开防抖共用同一计时通道**（主理人已确认保守口径）。

## 5. 参数
| 参数 | 值 | 单位 |
|---|---|---|
| guardDebounce | 200 | ms |
| stagger（弹开强后摇） | 400 | ms |
| 使用次数冷却 | 无 | - |
| 格挡次数 | 每姿态 1 次（碎裂即结束） | - |

## 6. 边界情况
1. 冲撞起手/判定/后摇期间按右键 → 忽略（不做取消，保持两键职责纯净）。
2. 弹开期间按右键 → 忽略（眩晕中不可防御）。
3. 防御中被第二次冲撞命中 → 不存在：第一次命中即碎裂结束姿态，后续命中按普通命中死亡。
4. 双方同时防御 → 合法状态，僵局由任一方打破（先动者进入对撞规则域）。
5. 幽灵的 guard_begin/guard_end 事件驱动同一套规则（见 mirror-ai.md）。
6. hitstop/慢放期间按住右键 → 状态时间轴统一走缩放后时间，防止时长漂移。
7. 松开瞬间恰被命中（同帧 mouseup + 命中）→ 以该帧开始时的姿态状态为准（松开在帧末生效），判格挡成功。

## 7. 特效与反馈
- 呼吸光晕：半径 16→22px 正弦振荡（周期 800ms），透明度 0.5±0.15。
- 护盾碎裂：光圈炸裂成 8~10 碎片粒子 + 60ms hitstop（格挡命中感）。
- 攻击者弹开：色闪（白↔受击色 3 次闪烁/400ms）+ 位置抖动 ±2px。
- 防抖期内尝试开启 → 光球轻微暗淡 50ms（负反馈，与旧闪避冷却反馈一致的手感语言）。

## 8. 验收标准
- [ ] 按住右键 100% 进入姿态且位移为 0。
- [ ] 姿态期第一次冲撞命中 100% 格挡成功、攻击者眩晕 400ms、防御者不死。
- [ ] 碎裂后 200ms 内再按右键无效。
- [ ] mouseup/mousedown 事件在失焦时不残留姿态。
- [ ] 边界情况 7（同帧松开+命中）判定确定且可复现。

# v2.3 增量 · 防御冷却重做（替换 v1.1 §4 冷却条款与 §5 防抖参数）

## A. 姿态时长
- 最长防御 **3 秒**：按住超时自动结束（视同"未被打的满额结束"，走分支 c）。
- 姿态结束方式三种：提前松开 / 超时满额 / 被打碎裂。

## B. 冷却规则（三分支，替换 v1.1 的 200ms 防抖——**防抖废除**）
| 分支 | 条件 | 冷却 |
|---|---|---|
| a. 提前松开 | 未被打、按时长 t < 3s 松开 | **冷却 = t**（防御多久还多久，例：按 2s → 冷却 2s） |
| b. 格挡碎裂 | 防御中被打（格挡成功） | 冷却 **3s**（格挡语义不变：攻击者弹开 400ms、护盾碎裂、姿态立即结束） |
| c. 满额结束 | 按满 3s 未被打，超时自动结束 | 冷却 **3s** |
- 分支 a **无下限**：瞬发松开 ≈ 0 冷却——这是用户有意设计的**预判弹反空间**，不是漏洞。
- 冷却自姿态结束帧起算；冷却期间右键无效（负反馈沿用：光球暗淡 50ms）。
- 姿态期时间轴走缩放后时间（hitstop/慢放同步缩放，v1.1 口径不变）。

## C. 边界情况
1. **满额瞬间被打**（同帧超时+命中 / 同帧松开+命中）→ **格挡优先**：以该帧开始时的姿态状态为准（帧末才生效松开/超时），判格挡成功走分支 b。与 v1.1 边界 7 的"帧首状态为准"裁定同源。
2. 分支 a 计时精度：t 按逻辑帧累计（60Hz），最小分辨率 16.7ms。
3. 冷却中被打死 → 冷却状态随死亡流程终止（无跨局残留）。
4. R 重试 / 自动推进下一关 → 冷却清零，姿态状态复位。
5. 幽灵侧同样适用三分支（guard 事件驱动，见 mirror-ai.md v2.3）。

## D. 特效增量
- 超时满额结束：光晕**温和淡出 200ms**（区别于碎裂炸开）。
- 冷却剩余可视化（建议级，可不做）：姿态期光晕外圈剩余时间弧 + 冷却期光球底部冷却弧。

## E. 参数表【v2.3 替换】
| 参数 | v1.1 | v2.3 |
|---|---|---|
| guardDebounce | 200ms | **废除** |
| 最长姿态时长 | 无 | **3000ms** |
| 分支 a 冷却 | - | = 已防御时长 t |
| 分支 b/c 冷却 | - | 3000ms |
| stagger（格挡弹开） | 400ms | 400ms（不变） |

## F. 验收

- [ ] 瞬发松开冷却 ≈ 0（≥0 且 <17ms）。
- [ ] 满额瞬间被打 100% 判格挡（帧首状态为准）。
- [ ] 超时自动结束触发且走温和淡出特效。

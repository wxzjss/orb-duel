# GDD · 冲撞系统（v1.1 全文重写，替代原"突进攻击"）

> v1.1 变更：左键由"朝准星突进斩击"改为"朝移动方向冲撞"，冲撞距离大幅提升；新增对撞裁决（后撞的赢）。原闪避系统废弃（见 dodge.md）。

## 1. 概述
左键触发沿移动方向的冲撞，是唯一击杀手段。三段结构：起手 → 冲撞判定 → 后摇。核心博弈：冲撞方向 = 你的移动方向（可被预读），对撞时后起手者赢。

## 2. 目标
- 冲撞距离 168px，威胁半径显著大于 v1.0 的 63px，鼓励对峙与诱敌。
- 方向绑定移动输入 → "想往哪撞就得往哪走"，制造可读的起手预兆。
- 对撞裁决"后撞的赢"确立后发制人博弈。

## 3. 输入
- 鼠标左键 mousedown。
- 方向解析优先级：
  1. 当前移动输入方向（WASD 向量归一化）
  2. 无移动输入 → 最后一次非零移动方向（记忆缓存）
  3. 从未移动过 → 朝鼠标方向兜底

## 4. 规则
- 三段：起手 70ms（蓄力微缩+方向锁定）→ 冲撞判定 120ms（1400 px/s，起点到端点线性插值，端点 = 起点 + dir×168px）→ 后摇 150ms。总冷却 340ms（后摇结束即可再撞）。
- 冲撞判定帧内按插值推进位置，墙体裁剪只缩短实际位移、不缩短判定帧时长。
- **命中规则不变**：打击圈（r20 @球心前方18px）vs 本体圈（r16）相交 → 被命中方死。
- **对撞裁决（新核心）**：双方均处冲撞判定帧且互相命中 → 比较 t_startTick（进入冲撞判定帧的逻辑帧号，整数）：**后起手（帧号大）者赢，先起手者死**。同一 tick 起手 → DRAW（同归于尽，见 level-flow）。
- 冲撞命中防御中的目标 → 不构成对撞，走格挡流程（见 guard.md）：攻击者进 400ms 弹开强后摇。
- 命中非判定帧状态的敌人（起手/后摇/移动中）→ 正常击杀，无对撞裁决。

## 5. 参数
| 参数 | 值 | 单位 |
|---|---|---|
| chargeWindup | 70 | ms |
| chargeActive | 120 | ms |
| chargeRecovery | 150 | ms |
| chargeSpeed | 1400 | px/s |
| chargeDistance | 168 | px（=1400×0.12） |
| 冷却（出招到可再撞） | 340 | ms |
| hitCircleR / hitCircleOffset / bodyR | 20 / 18 / 16 | px |

## 6. 边界情况
1. 起手后按方向键 → 方向不修正（起手即锁定），保证可读性。
2. 冲撞中途撞墙 → 位置 clamp，判定帧走完（贴墙撞有效）。
3. 冲撞中死亡 → 立即终止冲撞状态进死亡流程。
4. 冷却中点击 → 忽略不排队。
5. 对撞裁决仅在双方都处判定帧时触发；一方在起手/后摇被打 → 正常死（后撞的赢只保护"已在判定帧里的人"，不保护前摇）。
6. 对撞同 tick → DRAW，录制数据不重录（沿用既有流程）。
7. 一方在防御姿态被撞 → 不算对撞，攻击者进弹开（见 guard.md §4）。

## 7. 特效与反馈
- 起手：光球收缩至 85% + 沿冲撞方向的蓄力拉丝（指向预告，对手可读）。
- 判定：球体拖出 168px 冲撞光带 + 撞击点星芒。
- 对撞：双倍爆裂 + 更重 hitstop（见 fx.md）。
- 弹开：攻击者色闪+抖动（见 fx.md）。

## 8. 验收标准
- [ ] 点击到起手延迟 ≤ 1 帧。
- [ ] 冲撞位移实测 ≈168px（无墙时），方向 = 移动输入方向。
- [ ] 方向解析三级回退链逐一验证（移动中/静止有记忆/从未移动）。
- [ ] 对撞裁决：构造先后差 1 帧的两方冲撞，100% 判先起手者死；同帧 100% DRAW。
- [ ] 命中防御者时 100% 走格挡流程，不误判死亡。

## 建议（主理人已确认，实现侧必须遵守）
- chargeActive 120ms 内打击圈随球心移动，**实现时每帧重算圈位（勿起手时一次算死）**。

# v2.2 增量 · 三次击杀与命中矩阵

## A. HP 规则（废除一击必杀）
- 双方各 **HP = 3**，每次有效命中 −1，归 0 进入现行死亡流程（特效/慢放/重试/结算全部不变）。
- 胜负语义：击败 = 打空对方 HP。**boss 计数器、replay 录制、替换/晋级/删除语义全部不变**（一次对局仍产一份 replay）。
- HP 无回复；R 重试 / 自动推进下一关时双方 HP 重置为 3。

## B. 攻击无敌
- 起手（50ms）+ 判定帧（100ms）期间无敌；后摇（50ms）可被打。
- 被无敌目标"挡下"的命中 = 无效（不掉血、不计数、不弹开）。

## C. 对撞弹开（废除「后撞的赢」与 t_startTick 裁决）
- 双方均处判定帧且接触 → 沿连线互相弹开，**双方不掉血**，各进 **300ms 弹开**（轻于防御触发的 400ms）：
  - 弹开位移：沿连线各击退 60px / 150ms（含碰撞分离），剩余 150ms 为硬直；
  - 弹开/硬直期间：不可冲撞、不可防御（与 400ms 同语义）；
- 弹开结束时自然恢复行动。同帧同 tick 对撞 → 同样弹开（不再有 DRAW）。

## D. 命中矩阵（攻击方判定圈接触目标本体圈时）
| 目标状态 | 结算 |
|---|---|
| 普通（空闲/移动/后摇/弹开） | 有效命中：目标 −1 HP |
| 无敌·起手（蓄力未判定） | 无效命中：不掉血，光刃消散 |
| 无敌·判定帧（双方对撞） | 对撞弹开（双方不掉血，各进 300ms 弹开） |
| 防御姿态 | 格挡：攻击者弹开 400ms、防御者护盾碎裂姿态结束（不掉血，规则不变） |

- 每次冲撞对同一目标至多结算一次命中（命中即标记，判定帧剩余时间不重复结算）。

## E. 实体碰撞（任何状态）
- 两球本体圈重叠 → 沿连线位置分离至恰好不重叠（软推挤，无伤害、无特效、不触发任何状态）。
- 冲撞端点计算考虑碰撞截停：判定圈始终随实际球心；穿墙 clamp 规则不变。

## F. 参数增量
| 参数 | 值 | 单位 |
|---|---|---|
| maxHP | 3 | - |
| clashStagger（对撞弹开） | 300 | ms |
| clashKnockback | 60 px / 150 ms | - |

## G. 边界情况
1. 攻击周期 200ms 中无敌 150ms——滥用自查已由主理人裁定接受：反制 = 防御弹开 400ms 与对撞弹开；QA 侧重点观察"无敌推进"是否成主导策略。
2. 判定圈命中无敌目标且随后滑入防御目标范围（同一判定帧）→ 按接触时刻目标状态逐帧结算（矩阵逐帧套用）。
3. 对撞弹开把一方推入墙体 → clamp，另一方照常弹完。
4. 教学木桩 HP=3：教学关需命中 3 次（教学次数变多，正好熟悉连招节奏，接受）。
5. DRAW 状态：**dormant**——代码保留，当前无触发源（同 tick 对撞已改弹开）；若未来恢复一击必杀类规则再启用。

## H. 验收补充
- [ ] 命中矩阵四行逐一构造验证，无误判路径。
- [ ] 对撞双方 HP 均不减、均进 300ms 弹开、位置分离无重叠。
- [ ] HP=0 才触发死亡；R 重试后双方 HP=3。
- [ ] 实体碰撞任何状态组合下无穿模（含双方同时冲撞交错场景）。

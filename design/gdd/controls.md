# GDD · 玩家操控系统

## 1. 概述
玩家光球的移动控制。零惯性、即时响应，是"三键极速"支柱的地基。

## 2. 目标
- 按下即达：无加速/减速曲线，手感如光标般直接。
- 与攻击/闪避的状态锁正确互斥。

## 3. 输入
- WASD / 方向键：keydown 开始移动、keyup 停止（记录按键集合）。
- 移动向量 = 各方向键代数和后归一化（对角线不加速）。

## 4. 规则
- 速度恒定 320 px/s，无惯性。
- 位置每帧 clamp 到 [16, 1264]×[16, 704]（含半径内缩）。
- **状态锁**：攻击前摇+判定帧期间移动输入被忽略；闪避冲刺期间移动输入被忽略。攻击后摇期间恢复移动。

## 5. 参数
| 参数 | 值 | 单位 |
|---|---|---|
| moveSpeed | 320 | px/s |
| orbRadius | 16 | px |
| 边界内缩 | 16 | px |

## 6. 边界情况
1. 对向键同按（A+D）→ 向量和为 0，原地不动。
2. 攻击/闪避中按键 → 缓存按键集合，状态结束后立即生效（不吞输入）。
3. 失焦（blur）→ 清空按键集合，防止"幽灵键"持续移动。
4. 边界挤压：闪避被墙体截断时位置 clamp，不穿墙。

## 7. 特效与反馈
- 移动拖尾：每 40ms 落一枚淡出光点（寿命 200ms，透明度 0.25→0）。
- 移动方向相反时球体轻微拉伸 5%（squash & stretch）。

## 8. 验收标准
- [ ] 按键到位移的延迟 ≤ 1 帧（16.7ms）。
- [ ] 对角线速度 = 直线速度（归一化正确）。
- [ ] 攻击判定帧期间位移为 0。
- [ ] 切出窗口再切回不出现持续移动。

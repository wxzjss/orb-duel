# GDD · 关卡流转状态机（含教学木桩逻辑与胜负判定）

## 1. 概述
全局状态机，管理教学关、木桩、关卡衔接、死亡重开与胜利结算。

## 2. 目标
- "木桩死亡 → 幽灵登场"的转折瞬间要干脆、有仪式感。
- 死亡惩罚轻（秒级重开），支撑"一击必杀"的高频重试节奏。

## 3. 输入
- 状态机事件：木桩/玩家/幽灵死亡、按键（R 重开、任意键继续）。

## 4. 规则（状态机）
```
BOOT → TUTORIAL → TUTORIAL_CLEAR → LEVEL1 → VICTORY
                       ↑               ↓
                       └── DEATH ←─────┘（玩家死 → R/点击 → 重进 LEVEL1）
```
- **TUTORIAL**：木桩位于玩家出生点正对面（(1050, 360)），**不移动、不攻击、不闪避**，仅可被击杀。Recorder 同步开启。
- **TUTORIAL_CLEAR 触发**：木桩死亡帧。流程：Recorder.finalize()（120ms hitstop 内完成）→ 120ms hitstop + 木桩爆裂 → 1.2s 横幅"第一关：它学会了你"→ 切 LEVEL1。
- **LEVEL1**：幽灵在 (230, 360) 出生（offset 由幽灵出生点与玩家教学关出生点之差确定），回放开始。
- **DEATH**：玩家死亡 → 1.0s 慢放死亡 → 显示"被自己击败 · R 重试"。
- **VICTORY**：幽灵死亡 → "你击败了你自己 · 用时 X 秒 · 重玩按 R"（**R → 重进 LEVEL1，沿用同一 replay 不重录**——主理人 v1 裁定：与 DEATH 路径统一重试节奏，原"清空录制回 TUTORIAL"作废，以 architecture.md §2.8 为准）。
- **平局**（同帧互杀）→ 直接重进 LEVEL1，数据不重录。【已拍板】

## 5. 参数
| 参数 | 值 |
|---|---|
| 木桩出生点 | (1050, 360) |
| 幽灵出生点 | (230, 360) |
| 衔接横幅时长 | 1200 ms |
| 死亡慢放 | 1000 ms @ timeScale 0.3 |
| hitstop | 120 ms |

## 6. 边界情况
1. 玩家在教学关死亡 → 不可能（木桩无攻击），防御性断言 + 回 TUTORIAL 出生点。
2. 横幅期间按键 → 忽略全部输入（防误触跳过）。
3. R 重试时 Recorder 状态 → 不重录教学关数据，沿用原数据。
4. 平局连锁（重开又平局）→ 正常循环重开，无次数限制。

## 7. 特效与反馈
- 状态切换均以死亡爆裂 + hitstop 为节拍点（详见 fx.md）。
- TUTORIAL_CLEAR 横幅：黑底白字浮现，配低频音，制造"平静后的不安"。

## 8. 验收标准
- [ ] 木桩死亡到幽灵开始回放的全程过渡 ≤ 1.5s 且无帧冻结。
- [ ] 任何死亡路径都能在 2 次点击内回到可玩状态。
- [ ] 状态机无死状态（穷举：胜利/失败/平局/重试全路径测试）。

# v2.0 增量 · 关卡流转状态机扩展（主菜单与多模式）

> v1.x 的 BOOT→TUTORIAL→...→VICTORY 主链保留为「单机挑战」模式的内部流程，以下为增量。屏幕层设计见 architecture-v2.0-patch.md §1。

## 状态机扩展（顶层）
```
MENU ──单机挑战──→ [v1 主链不变] ──胜利──→ MENU（replay 流向播种，见 modes.md §4）
 ├──联机挑战──→ SERVE_ONLINE → MATCH_ONLINE ──胜/负──→ REPORT → MENU
 ├──挑战自我──→ MATCH_SELF(N) ──胜→替换/推进──→ MATCH_SELF(N+1)…；负→RETRY
 ├──挑战boss─→ BOSS_SUBMENU ──单机boss──→ MATCH_LOCALBOSS(K) → REPORT_LOCAL → MENU
 │                        ├──联机boss──→ MATCH_ONLINEBOSS → REPORT → MENU
 │                        └──终极boss──→ MATCH_ULTIMATE → REPORT → MENU
 └──退出游戏──→ CONFIRM_QUIT → CLOSE / FAREWELL
```

## 新增状态说明
- **MENU / BOSS_SUBMENU**：DOM overlay 菜单态（ADR-005），规格见 menu.md；灰显判定在进入时刷新。
- **SERVE_ONLINE**：请求服务端抽取（联机池/联机boss随机，终极boss取队列头）；失败→toast 回 MENU。
- **MATCH_***：全部复用现有对局循环（含 DRAW 流程）；差异仅在于幽灵 replay 来源与 HUD 进度条。
- **REPORT**：结算上报（本地池写 localStorage / 服务端 report_result），完成后按模式跳转（挑战自我胜→下一关，其余→MENU）。
- **RETRY**：挑战自我/单机boss失败 → 原地重试（无次数限制，语义同 v1 DEATH 等 R）。
- **FAREWELL**：window.close() 被拦截时的告别画面（menu.md §4.1）。
- 原 BOOT 态移除：启动引导归屏幕层（architecture-v2.0-patch.md §1）。

## Recorder 全局化（关键变更）
- 录制窗口不再绑定教学关：**任何模式任何对局，从开局到出现死亡结果帧全程录制**，产出 {traj, events, meta}。
- 教学关录制 = 单机挑战内部行为（提供镜像关幽灵），不再独占 Recorder。
- 玩家中途 ESC 放弃 → 录制作废丢弃。

## 边界情况（流转级）
1. REPORT 期间断线 → 本地对局已成立的结果缓存，恢复连接后补报（服务端幂等）；超时放弃则丢弃。
2. 挑战自我 RETRY 不重置该关幽灵计数（幽灵打死你 +1，正是晋级的燃料）。
3. 从对局 ESC 返回 MENU 后再进入同模式 → 重新抽取（联机类）/ 原地继续（挑战自我解锁关不变）。

## 验收标准（v2.0 增量）
- [ ] 五模式进出与 v1 主链互不污染（状态机无非法迁移）。
- [ ] 任何对局结束路径（胜/负/DRAW/放弃/断线）对 Recorder 产物的处理符合 Recorder 全局化规则。

# v2.1 增量 · 开机屏与单机挑战无限关卡链

## A. 开机屏（初始界面回滚 v1.0）
```
BOOT → TITLE（初版开机观感：标题 + 「点击屏幕开始」） ──点击一次──→ MENU（v2.0 菜单不动）
```
- TITLE 只响应一次点击（任意位置），点击即入 MENU；无其他交互。
- ESC/返回键永不回到 TITLE（仅退出游戏流程可达）。

## B. 单机挑战无限关卡链（AUTO_ADVANCE 语义）
```
LEVEL 1（教学木桩）──击杀→ AUTO_ADVANCE ──1.2s 横幅「第 2 关：它学会了你」──→ LEVEL 2（镜像幽灵=教学段录制）
LEVEL N（N≥2）──击杀→ AUTO_ADVANCE ──1.2s 横幅「第 N+1 关」──→ LEVEL N+1 ──…无限延续
```
- **AUTO_ADVANCE**：击杀帧 → 120ms hitstop + 死亡爆裂 → 1.2s 横幅 → 直接进下一关，**无需任何确认输入**。
- **幽灵来源**：
  - 第 2 关：教学关录制（现行 mirror 语义，不变）。
  - **第 3 关起：上一关的胜利 replay**——你打败第 N 关所用那局的操作，作为第 N+1 关的幽灵（打「上一关的你」）。喂入走 ServeProvider，无新接口。
- **无人工难度缩放**：链条难度自然涌现（越往后的幽灵越是"刚打赢强敌的你"）。
- **死亡**：R 原地重试当前关（幽灵数据不变，即重打同一个 replay）；ESC 放弃 → 确认框 → 回主菜单。
- **录制**：按对局尝试分段——每次尝试（重开起）为新录制段，胜负皆产出（语义同 v2.0 Recorder 全局化）；仅胜利段用于幽灵喂入与播种。
- **播种窗口收窄**：仅**第 2 关胜利 replay** 播种挑战自我第 1 关（及联机池，同收窄口径）；第 3 关起的胜利 replay 不播种任何池（避免无限链污染资产池）。
- **关卡 UI**：AUTO_ADVANCE 横幅显示「第 N 关」（第 2 关附副标「它学会了你」）；HUD 左上角常驻小字「第 N 关」，与 boss 模式进度条互斥显示（按当前模式二选一）。

## C. 边界情况
1. 第 N 关重试不重置链条：击败后仍从第 N+1 关继续（解锁进度=本局最远到达关）。
2. ESC 确认框期间恰逢 AUTO_ADVANCE → AUTO_ADVANCE 优先完成（已击杀即锁定推进）。
3. 第 2 关横幅期间 Recorder 已闭合教学段（v1 语义不变）；第 3 关起横幅期间新录制段尚未开始（幽灵喂入用的是上一关胜利段，无需等待）。
4. 无限链与挑战自我/联机池完全隔离（收窄后无交叉写入）。

## D. 验收标准
- [ ] 击杀到下一关开始全程无任何必需输入（自动横幅推进）。
- [ ] 第 3 关幽灵轨迹 = 第 2 关胜利段 replay（ServeProvider 断言）。
- [ ] R 重试喂入幽灵与首次一致；播种仅发生在第 2 关胜利。
- [ ] TITLE 点击一次直达 MENU；HUD「第 N 关」在单机挑战外不显示。

# v2.2 增量 · 固定站位 + HP 死亡门槛

## A. 固定站位（全模式统一）
- **玩家永远出生左侧 (230, 360)；幽灵永远出生右侧 (1050, 360)**。含：教学关木桩位 (1050,360) 不变、镜像关、挑战自我、全部 boss 模式。
- **offset = ghostSpawn − playerSpawn = (820, 0)**，仍由 CONFIG 按出生点推导，勿硬编码数值。
- 架构文档 §2.8「主客互换」段**作废**（v2.2 起不存在主客互换，站位恒定）。

## B. HP 死亡门槛
- 死亡触发条件由"被命中一次"改为"**HP 归 0**"（HP=3）。死亡流程（慢放/R 重试/自动推进/结算上报）与计数器语义完全不变。
- 胜利 = 打空幽灵 HP → AUTO_ADVANCE（无限关卡链 v2.1 语义不变）；失败 = 自己 HP 归 0 → R 原地重试（双方 HP 重置 3）。
- DRAW 状态 dormant：同 tick 对撞已改弹开，平局路径暂无触发源（保留代码，勿删）。

## C. 边界情况
1. v2.0 播种/晋级/替换规则不受 HP 影响（replay 仍按整局录制，对局长度可能变长，录制上限 600s 不变）。
2. 弹开（300/400ms）期间不存在第三方（1v1），无该场景。
3. 教学关木桩 HP=3：玩家需命中 3 次，教学段录制时长相应变长，回放照常。
4. 血条 UI 随关卡链跨关保留（每关重置满格）。

## D. 验收
- [ ] 全模式出生点实测符合固定站位；offset 由 CONFIG 推导值 = (820,0)。
- [ ] HP 归 0 才进死亡流程；现行所有结算路径回归通过。
- [ ] v2.1 无限关卡链（AUTO_ADVANCE/播种收窄）在 HP=3 下回归无破坏。

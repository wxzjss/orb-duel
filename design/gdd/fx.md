# GDD · 特效表现系统（v1.1 修订版）

## 1. 概述
一击必杀没有血条，全部游戏感由特效承载。所有特效走 Canvas 加法混合 + 粒子池，不做 DOM/图片资产（纯代码绘制，适配原生 JS 约束）。

## 2. 目标
- 每个动词（走/撞/防/死）都有独占视觉签名，0.5 秒内可读。
- 性能预算：60fps 下峰值粒子 ≤ 300。

## 3. 输入
- 各系统发出的 fx 事件：onMove / onCharge(windup|active) / onGuard(begin|break) / onBounce / onDeath / onLoopSeam。
- v1.1 移除：onDodge、onGraze（擦弹慢放随闪避废弃，其手感语言转移为格挡 hitstop）。

## 4. 规则
- 统一粒子池（预分配 300，复用死亡粒子），globalCompositeOperation='lighter'。
- timeScale 全局变量支撑 hitstop 与慢放（fx 驱动，逻辑层读取）。
- 【v1.1】hitstop 与慢放叠加时取 max（120ms hitstop 优先于 60ms 格挡 hitstop，不叠加成卡死）。
- 【v1.1】屏幕震动在**渲染层施加偏移**（作用于最终 drawImage/世界变换，不回写世界坐标）——这是 v1.0 的实现教训，坐标污染会导致逻辑位移漂移。

## 5. 参数【v1.1 修订】
| 特效 | 参数 |
|---|---|
| 死亡爆裂 | 14~18 粒子，速度 200~500px/s，寿命 500ms，+ 冲击环（r: 0→90px, 250ms） |
| 对撞死亡（对撞裁决触发） | 双倍爆裂（双方各 14~18）+ 冲击环 ×2 + hitstop 120ms |
| hitstop（死亡） | 120ms |
| hitstop（格挡碎盾） | 60ms |
| 屏幕震动 | 死亡 6px / 对撞 10px / 挥空 2px，指数衰减 200ms |
| 冲撞起手 | 球体收缩至 85% + 沿方向蓄力拉丝（长 40px，寿命 70ms） |
| 冲撞判定 | 168px 冲撞光带（寿命 120ms）+ 撞击点星芒（6 粒火花） |
| 防御光晕 guard_halo | 常驻附着光圈 r16→22 正弦呼吸（周期 800ms），透明度 0.5±0.15，非粒子，随姿态结束消散 |
| 护盾碎裂 shield_break | 光圈炸裂 8~10 碎片粒子（速度 200~300px/s，寿命 350ms）+ 60ms hitstop |
| 弹开眩晕 bounce_stun | 攻击者色闪（白↔受击色 3 次闪烁/400ms）+ 位置抖动 ±2px（渲染层偏移） |
| 移动拖尾 | 每 40ms 一枚光点，寿命 200ms（保留，v1.0 实现已验） |

## 6. 边界情况
1. 粒子池耗尽 → 复用最旧粒子（不崩溃、不丢死亡特效优先级）。
2. 慢放期间新死亡 → hitstop 叠加取 max，不叠加成卡死。
3. 标签页失焦 → requestAnimationFrame 自动暂停，恢复时 timeScale 强制复位 1。
4. 低帧率设备（<45fps 持续 2s）→ 关闭拖尾与星芒，保留死亡/冲撞/防御特效（降级开关）。
5. 【v1.1】guard_halo 为常驻附着型特效：进 GUARD 时创建、退出时销毁，不走粒子池（独立轻量对象，避免长驻占用池位）。

## 7. 特效与反馈
（本文件即特效规格；各系统 GDD 的第 7 节为需求来源，此处为实现口径。）

## 8. 验收标准【v1.1 修订】
- [ ] 1280×720 下 300 粒子峰值不掉帧（Chrome, 集显）。
- [ ] hitstop 期间粒子冻结、UI 不冻结。
- [ ] 失焦恢复无特效状态残留。
- [ ] 【v1.1】屏幕震动不改变任何逻辑坐标（震动前后实体位置逐位一致）。
- [ ] 【v1.1】guard_halo 创建/销毁与 GUARD 相位严格同步（退出后 0 帧残留）。
- [ ] 【v1.1】全局搜索 'dodge' 0 命中（渲染侧闪避残影路径已删净）。

---
**依赖说明**：fx 为纯下游消费方，不依赖任何系统内部状态，仅订阅事件 → 可与渲染层直接对接。

# v2.2 增量 · 受击反馈与血量 UI

## A. 受击反馈
| 项 | 参数 |
|---|---|
| 扣血白闪 | 受击球体白闪 80ms |
| 受击微震 | 屏幕震动 3px，衰减 120ms |
| 低血警示 | HP=1 时球体边缘持续微红脉动（周期 600ms） |
| 无效命中（打在无敌上） | 光刃提前消散（寿命缩至 40ms），无白闪无震动 |

## B. 对撞弹开特效（取代对撞双倍爆裂）
- 接触点双向冲击环：两个小环 r 0→40px，200ms，方向相反。
- 双方轻微白闪 60ms。
- **对撞双倍爆裂条目 → dormant**（对撞不掉血无死亡，无爆裂触发源；死亡爆裂本身照旧）。

## C. 实体碰撞：无特效（软推挤静默，避免视觉噪音）。

## D. 顶部血量 UI（双方屏幕上方各一组）
- 布局：玩家血条顶部居左偏中（组中心 x≈340），幽灵血条顶部居右偏中（组中心 x≈940），y=24。
- 样式：3 格光条，每格 24×10px，间隔 6px；满格亮（玩家暖白/幽灵冷青），扣血格熄灭（透明度 0.15）；扣血瞬间熄灭格闪红 150ms（受击指向性反馈）。
- 血条下方 8px 处配小字「你」/「幽灵」。
- **「第 N 关」小字移至顶部正中**（x=640），与两侧血条共存；boss 模式进度条仍在左上角纵排，互不重叠。
- 血条为纯 Canvas 绘制，随 hitstop/慢放冻结数值但不冻结熄灭闪烁动画。

## E. 验收
- [ ] 扣血→白闪+熄灭+红闪三反馈同帧一致。
- [ ] 血条布局与 boss 进度条、「第 N 关」小字无重叠（1280×720 实测）。
- [ ] 对撞时无爆裂残留，弹开双环正常播放。

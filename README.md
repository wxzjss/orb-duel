# 光球对决（Orb Duel）

俯视角 1v1 光球对决游戏 —— HTML5 Canvas + 原生 JS，单文件 `index.html`，双击即玩，零依赖零资产。

## 玩法
- **WASD / 方向键** 移动（零惯性）
- **左键** 朝移动方向冲撞（起手 50ms → 判定 100ms / 1680px/s / 168px → 后摇 50ms，总冷却 200ms）
- **右键长按** 防御（光晕护体，格挡一次冲撞并把攻击者弹开 400ms；最长防 3s，提前松开返还冷却）
- **三次击杀**：双方各 3 点血，打空才死；两球不能互穿，对撞互相弹开
- **镜像幽灵**：单机挑战打败对手后自动进下一关——从第 3 关起，每关的幽灵都是你打败上一关的那局操作（水平镜像复刻）。**你在教你的敌人杀你自己。**

## 模式
- **单机挑战**：无限关卡链，自动推进
- **挑战自我**：本地幽灵天梯，被打败就替换，20 胜封神进单机boss
- **单机boss**：自己养出来的怪物，20 次被挑战成功就删除、顺位前移
- **联机对战**（需运行 `node server.js`）：局域网创建/加入房间，P1/P2 + 观战席位（≤8），座位可设真人或 AI
- **AI 接口 `window.OrbAI`**：AI 直接函数调用读状态+发输入（零截屏零延迟），真人/AI 任意组合对战

## 运行
- **单机 / AI 对战**：浏览器直接打开 `index.html`
- **局域网对战**：房主运行 `node server.js`，其他设备浏览器访问 `http://<房主IP>:8080`

## 仓库结构
```
index.html   游戏本体（全部代码）
server.js    局域网对战服务端（Node + ws）
design/      设计文档（GDD）
docs/        架构文档与 ADR
tests/       Node 纯逻辑单测（selftest）+ 烟雾测试（smoke）
```

## 开发
```bash
node tests/selftest.js   # 纯逻辑单测
node tests/smoke.js      # 运行时烟雾测试
```
